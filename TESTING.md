# Ручная проверка Glassine

Сначала автотесты — они покрывают геометрию, имена файлов и форматы: `scripts/test.sh`.
Этот чек-лист — для того, что видно только глазами и руками.

Чек-лист перед коммитом крупной функции и после обновления macOS. Отмечайте `[x]` по ходу,
найденное — в issue или в ROADMAP.

## Подготовка

```bash
scripts/install.sh                                                     # собрать и поставить в /Applications
/usr/bin/log stream --predicate 'subsystem == "com.warhead88.glassine"' # логи в отдельном терминале
```

- Хоткеи по умолчанию: ⌘⇧4 — область, ⌘⇧5 — окно, ⌘⇧3 — экран, ⌥⇧⌘, — настройки (системные снимки macOS
  на этих клавишах нужно выключить: Keyboard → Keyboard Shortcuts… → Screenshots; Glassine подскажет)
  (на русской раскладке — клавиша «Б»). Повтор и таймер назначаются во вкладке Shortcuts.
- Для проверки без хоткея (только Debug): `open /Applications/Glassine.app --args --debug-preview`.

## 1. Запуск и разрешения

- [ ] Первый запуск (`defaults delete com.warhead88.glassine`, перезапуск) — окно приветствия с хоткеями
- [ ] Повторный запуск из Spotlight открывает настройки
- [ ] Без разрешения: окно приветствия с тремя шагами; «Allow Screen Recording…» показывает только системный
      запрос (никаких других окон); его «Open System Settings» → включить Glassine → «Quit & Reopen»
- [ ] После перезапуска с разрешением — окно «Screen Recording is on — you're all set» (один раз)
- [ ] Если системный запрос уже был, кнопка называется «Open System Settings…» и открывает раздел сразу
- [ ] После пересборки (`scripts/install.sh`) разрешение сохраняется
- [ ] Glassine не появляется в Dock; иконка в меню-баре — только если включена
- [ ] Если системные снимки macOS (⇧⌘3/4/5) включены — в окне приветствия и на вкладке Shortcuts
      оранжевая подсказка с кнопкой «Open Keyboard Settings…»; после выключения подсказка исчезает

## 2. Область (⌘⇧4) и окно (⌘⇧5)

- [ ] Экран «замирает», курсор — перекрестие, лупа показывает пиксели, координаты и HEX
- [ ] M прячет/показывает лупу, выбор запоминается (и совпадает с настройкой «Show magnifier»)
- [ ] Область: затемнение и белая рамка по краю экрана (углы скруглены, не обрезаются), окна не подсвечиваются,
      простой клик ничего не делает
- [ ] При старте области: плавное затемнение, рамка «проявляется» (всегда), тихий щелчок
- [ ] Settings → Capture → Area frame: «Around the notch» — рамка огибает чёлку снизу; «Straight» — прямая;
      на внешнем мониторе без чёлки рамка всегда прямая; «No frame» — только затемнение, без рамки
- [ ] Settings → Capture → Frame bottom corners: «Square» — нижние углы рамки прямые, верхние остаются скруглёнными;
      при «No frame» строка неактивна
- [ ] Settings → Capture → Sounds: звук при старте области и звук после снимка отключаются по отдельности
- [ ] Закрыть область (Esc) и сразу открыть снова — щелчок звучит каждый раз; то же для звука после частых снимков
- [ ] Окно (свой хоткей или пробел из области): окно под курсором не затемнено; клик — снимок только этого окна
      (с тенью / без — настройка); клик мимо окон ничего не делает; пробел — обратно в область
- [ ] Перетаскивание — область, подпись с размером в пикселях
- [ ] Shift — квадрат, ⌥ — от центра, зажатый пробел — двигает выделение
- [ ] Esc и правый клик — отмена без снимка
- [ ] После снимка или Esc активным остаётся то приложение, в котором вы работали
- [ ] Режим «Adjust, then press Return»: ручки, перетаскивание внутри, стрелки (Shift — по 10),
      двойной клик / Return — снимок
- [ ] Второй монитор: выделение на нём, подсветка окон на нём, превью появляется там же
- [ ] Превью и окна Glassine не попадают в снимок

## 3. Другие режимы

- [ ] ⌘⇧3 — снимок экрана, где находится курсор
- [ ] Повтор прошлой области — та же область без оверлея; до первого выделения — системный «бип»
- [ ] Таймер — обратный отсчёт по центру экрана, клик по нему отменяет; после отсчёта — обычный оверлей
- [ ] Меню иконки в меню-баре: все пункты работают и показывают хоткеи

## 4. Результат

- [ ] Копия в буфере (вставить в Telegram / Заметки), звук — если включён
- [ ] Файл в папке сохранения, имя «<префикс> ГГГГ-ММ-ДД at ЧЧ.ММ.СС»
- [ ] Форматы: PNG, JPEG, HEIC — файл открывается в Preview, размер в Preview = размеру на экране
- [ ] «Сохранять в 1x»: на Retina файл вдвое меньше по пикселям
- [ ] Свой префикс имени; символы `/` и `:` заменяются на `-`

## 5. Превью после снимка

- [ ] Появляется справа снизу маркой: перфорация по краям, снимок в паспарту, внизу дата курсивом
      Fraunces («22 окт. · 18:56» на русском) и размер в пикселях; у записи — «MP4 · 2 tracks» и «▶ 0:42»
- [ ] Стопка: до 5 превью, а на маленьком экране — сколько помещается, старые закрываются
- [ ] Наведение: снимок темнеет, Copy / Save (или Show in Finder) ниже угловых кнопок ✕, карандаш, пин —
      ничего не перекрывается даже на маленьком превью; QR — синяя кнопка и синий значок в углу; Copy → «Copied»
- [ ] Светлая и тёмная тема; Increase Contrast — без перфорации, обычная карточка
- [ ] Без рук: `--debug-preview` (`hover` — кнопки видны сразу, `light` — светлая тема)
- [ ] Перетаскивание в чат / письмо / Finder вставляет файл и закрывает превью
- [ ] Клик открывает редактор; правый клик — меню (Edit, Open in Preview, Save As…, Pin)
- [ ] Автоскрытие по таймеру, пауза при наведении; «Never» — не закрывается
- [ ] Фокус не уходит из текущего приложения, пока превью на экране

## 6. Пины

Для быстрой проверки без хоткея (Debug): `open /Applications/Glassine.app --args --debug-pins`.

- [ ] Кнопка 📌 в превью — пин появляется на месте снятого фрагмента, превью закрывается
- [ ] Пин из буфера: скопировать картинку (например, в Preview ⌘C) → хоткей «Pin from clipboard»;
      без картинки в буфере — «бип»
- [ ] Перетаскивание двигает пин; «Lock Position» запрещает; клик по пину не уводит фокус из текущего приложения
- [ ] Колесо / прокрутка двумя пальцами — масштаб вокруг курсора, бейдж с процентами; двойной клик и ⌘0 — 100 %
- [ ] ⌥ + колесо и меню Opacity — прозрачность
- [ ] Click Through: клик проходит в окно под пином; зажать ⌥⌘ — пин подсвечивается и снова
      кликабелен, в меню можно выключить режим
- [ ] ⌘C копирует, ⌘S — Save As…, Esc / ⌘W закрывают пин (после клика по нему)
- [ ] Включение Click Through показывает подсказку «hold ⌥⌘ to use the pin»
- [ ] Несколько пинов; ⌥⇧⌘P («Show/Hide Pins») прячет и возвращает все, «Close All Pins» закрывает все
- [ ] Если пин мешает и не кликается — ⌥⇧⌘P прячет его, перезапуск Glassine убирает все пины
- [ ] Пин виден на всех рабочих столах (Spaces) и поверх полноэкранных приложений
- [ ] Новый снимок не захватывает пины (они — окна Glassine)

## 7. Редактор

Без хоткея (Debug): `open /Applications/Glassine.app --args --debug-editor` — окно с образцами всех пометок.

- [ ] Клик по превью открывает редактор; «Edit» в меню превью и пина (⌘E) — тоже
- [ ] Каждый инструмент по кнопке и по клавише (V A L R O T D M N B P X C) — в том числе на русской раскладке
- [ ] После стрелки / фигуры / текста — сразу выделение с новой пометкой; перо, маркер, шаги остаются
- [ ] Ручки: растянуть прямоугольник, эллипс, рисунок пером; перетащить конец стрелки (Shift — 45°)
- [ ] Ползунок толщины: меняет новую и выделенную пометку, отмена — одним шагом; свой цвет из палитры
- [ ] Shift: квадрат / круг, стрелка и линия ровно по 45°
- [ ] Текст: клик — поле ввода, Return — готово, Esc — отмена; двойной клик по тексту — правка
- [ ] Шаги нумеруются 1, 2, 3…; после удаления одного — перенумеровываются
- [ ] Размытие и пикселизация скрывают содержимое, заливка закрашивает цветом
- [ ] Выделение: двигается мышью и стрелками, Delete удаляет, смена цвета/размера меняет выделенное
- [ ] Обрезка: рамка, затемнение снаружи, «Reset Crop»; экспорт — только обрезанная часть
- [ ] ⌘Z / ⇧⌘Z и кнопки ↶ ↷ отменяют и повторяют всё, включая перемещение, размер и обрезку
- [ ] Панели не перекрывают кнопки окна; на macOS 26+ — стекло, на 14–15 — полупрозрачный материал
- [ ] Copy / Save / Pin работают, статус «Copied» / «Saved…» / «Pinned»; Done закрывает окно
- [ ] Наведение на любой инструмент или кнопку — через полсекунды подсказка с описанием и клавишей;
      клик прячет её; подсказка Done описывает действие по текущим настройкам
- [ ] Сохранённый файл совпадает с видом в редакторе и в полном разрешении (Retina)
- [ ] Пока редактор открыт — иконка в Dock и ⌘-Tab, после закрытия исчезает
- [ ] Редактор открывается с «Выделением»; ⌘M сворачивает; клик по иконке в Dock разворачивает его
      и не открывает настройки
- [ ] Фон (🖼): отступ, скругление, тень; заливки «продолжить», прозрачная (шахматка), цвета, градиенты
- [ ] Стрелка / текст за край снимка — фон расширяется и в редакторе, и в сохранённом файле
- [ ] Клик или протягивание пером / фигурой по тёмному полю вокруг документа ничего не рисует;
      протягивание за край окна не уводит пометку дальше видимой области
- [ ] Скругление без отступа → в PNG углы прозрачные; ⌘Z отменяет изменение фона одним шагом

## 8. Умные функции

- [ ] ⌥⇧⌘T: подсказка вверху; выделить абзац → «Text copied · N lines», текст в буфере по порядку строк
- [ ] ⌥⇧⌘T: клик по окну — текст всего окна; русский и английский вперемешку

- [ ] Несколько QR в одном снимке → «QR Codes (n)…»: список по порядку чтения, Copy All, Open для ссылок;

- [ ] Область без текста → «No text found»
- [ ] «Copy Text» в меню превью (правый клик) и пина
- [ ] ⌥⇧⌘C: клик копирует цвет, уведомление с образцом; формат из настроек (HEX/RGB/HSL)

## 10. Производительность

Цели — в «Принципах» ROADMAP.md. Последние замеры — там же, в этапе 1.1.

```bash
PID=$(pgrep -x Glassine)
footprint -p $PID | head -3                       # память (Footprint)
top -l 5 -s 2 -pid $PID -stats cpu,idlew          # CPU и пробуждения в простое
leaks $PID | grep "leaks for"                     # утечки
/usr/bin/log show --last 10m --predicate 'subsystem == "com.warhead88.glassine" AND eventMessage CONTAINS "Overlay ready"' --style compact
```

- [ ] В простое ~10 МБ и 0 % CPU
- [ ] «Overlay ready» < 150 мс (кроме первого захвата после запуска)
- [ ] После 10 снимков с превью память перестаёт расти, `leaks` — 0

## 11. Обновления

- [ ] `open /Applications/Glassine.app --args --debug-update` — окно с примером: разделы цветные,
      Skip This Version / Later / Update; крестик закрывает
- [ ] Settings → General → Updates: версия видна, переключатель автопроверки сохраняется,
      «Check for Updates…» — «Checking…», затем «You're up to date» (или найденное обновление)
- [ ] Полный цикл на локальном фиде: собрать копию с большей версией, подписать `sign_update`, отдать

- [ ] Фоновая проверка нашла обновление — окно появляется, но фокус остаётся в текущем приложении;
