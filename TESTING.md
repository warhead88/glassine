# Ручная проверка Glassine

Чек-лист перед коммитом крупной функции и после обновления macOS. Отмечайте `[x]` по ходу,
найденное — в issue или в ROADMAP.

## Подготовка

```bash
scripts/install.sh                                                     # собрать и поставить в /Applications
/usr/bin/log stream --predicate 'subsystem == "com.warhead88.glassine"' # логи в отдельном терминале
```

- Хоткеи по умолчанию: ⌘⇧2 — область/окно, ⌘⇧1 — экран, ⌥⇧⌘, — настройки
  (на русской раскладке — клавиша «Б»). Повтор и таймер назначаются во вкладке Shortcuts.
- Для проверки без хоткея (только Debug): `open /Applications/Glassine.app --args --debug-preview`.

## 1. Запуск и разрешения

- [ ] Первый запуск (`defaults delete com.warhead88.glassine`, перезапуск) — окно приветствия с хоткеями
- [ ] Повторный запуск из Spotlight открывает настройки
- [ ] Без разрешения на запись экрана ⌘⇧2 открывает окно приветствия, «Grant Access…» ведёт в System Settings
- [ ] После пересборки (`scripts/install.sh`) разрешение сохраняется
- [ ] Glassine не появляется в Dock; иконка в меню-баре — только если включена

## 2. Область и окно (⌘⇧2)

- [ ] Экран «замирает», курсор — перекрестие, лупа показывает пиксели, координаты и HEX
- [ ] M прячет/показывает лупу, выбор запоминается (и совпадает с настройкой «Show magnifier»)
- [ ] Окно под курсором не затемнено и обведено тонкой белой рамкой; клик — снимок только этого окна (с тенью / без — настройка)
- [ ] Клик по рабочему столу — снимок всего экрана
- [ ] Перетаскивание — область, подпись с размером в пикселях
- [ ] Shift — квадрат, ⌥ — от центра, зажатый пробел — двигает выделение
- [ ] Esc и правый клик — отмена без снимка
- [ ] После снимка или Esc активным остаётся то приложение, в котором вы работали
- [ ] Режим «Adjust, then press Return»: ручки, перетаскивание внутри, стрелки (Shift — по 10),
      двойной клик / Return — снимок
- [ ] Второй монитор: выделение на нём, подсветка окон на нём, превью появляется там же
- [ ] Превью и окна Glassine не попадают в снимок

## 3. Другие режимы

- [ ] ⌘⇧1 — снимок экрана, где находится курсор
- [ ] Повтор прошлой области — та же область без оверлея; до первого выделения — системный «бип»
- [ ] Таймер — обратный отсчёт по центру экрана, клик по нему отменяет; после отсчёта — обычный оверлей
- [ ] Меню иконки в меню-баре: все пункты работают и показывают хоткеи

## 4. Результат

- [ ] Копия в буфере (вставить в Telegram / Заметки), звук — если включён
- [ ] Файл в папке сохранения, имя «<префикс> ГГГГ-ММ-ДД at ЧЧ.ММ.СС»
- [ ] Форматы: PNG, JPEG, HEIC — файл открывается в Preview, размер в Preview = размеру на экране
- [ ] «Сохранять в 1x»: на Retina файл вдвое меньше по пикселям
- [ ] Свой префикс имени; символы `/` и `:` заменяются на `-`

## 5. Превью после снимка

- [ ] Появляется справа снизу; несколько снимков складываются в стопку (до 5)
- [ ] Наведение — кнопки Copy / Save (или Show in Finder); Copy → «Copied»
- [ ] Перетаскивание в чат / письмо / Finder вставляет файл и закрывает превью
- [ ] Клик открывает снимок в Preview; правый клик — меню, Save As… сохраняет в выбранное место
- [ ] Автоскрытие по таймеру, пауза при наведении; «Never» — не закрывается
- [ ] Фокус не уходит из текущего приложения, пока превью на экране

## 6. Пины

Для быстрой проверки без хоткея (Debug): `open /Applications/Glassine.app --args --debug-pins`.

- [ ] Кнопка 📌 в превью — пин появляется на месте снятого фрагмента, превью закрывается
- [ ] Пин из буфера: скопировать картинку (например, в Preview ⌘C) → хоткей «Pin from clipboard»;
      без картинки в буфере — «бип»
- [ ] Перетаскивание двигает пин; «Lock Position» запрещает
- [ ] Колесо / щипок — масштаб вокруг курсора, бейдж с процентами; двойной клик и ⌘0 — 100 %
- [ ] ⌥ + колесо и меню Opacity — прозрачность
- [ ] Click Through: клик проходит в окно под пином; зажать ⌥⌘ — пин подсвечивается и снова
      кликабелен, в меню можно выключить режим
- [ ] ⌘C копирует, ⌘S — Save As…, Esc / ⌘W закрывают пин (после клика по нему)
- [ ] Включение Click Through показывает подсказку «hold ⌥⌘ to use the pin»
- [ ] Несколько пинов; ⌥⇧⌘P («Show/Hide Pins») прячет и возвращает все, «Close All Pins» закрывает все
- [ ] Если пин мешает и не кликается — ⌥⇧⌘P прячет его, перезапуск Glassine убирает все пины
- [ ] Пин виден на всех рабочих столах (Spaces) и поверх полноэкранных приложений
- [ ] Новый снимок не захватывает пины (они — окна Glassine)

## 7. Настройки (⌥⇧⌘,)

- [ ] Все четыре вкладки открываются, изменения применяются без перезапуска
- [ ] Переназначение хоткея работает сразу
- [ ] «Launch at login» — Glassine появляется в System Settings → General → Login Items
- [ ] ⌘W закрывает окно, ⌘Q завершает приложение, когда окно в фокусе
