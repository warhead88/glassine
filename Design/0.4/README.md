# Glassine 0.4 — дизайн

Новый облик Glassine: пергамин, чернила и штемпель. Папка самодостаточная — её можно целиком
перенести в репозиторий приложения, например как `Design/0.4/`.

| Файл | Что |
|---|---|
| [DECISIONS.md](DECISIONS.md) | Принятые решения и почему: направление, цвет, стили, акцент |
| [TOKENS.md](TOKENS.md) | Палитра по ролям, акценты, шрифты, радиусы, контраст |
| [tokens.json](tokens.json) | Те же токены в машиночитаемом виде — один источник для сцен, приложения и сайта |
| [BACKLOG.md](BACKLOG.md) | Что сделать в коде и что ещё проверить |
| [SITE.md](SITE.md) | План сайта: структура и функции |
| `scenes/` | Векторные сцены: генератор, SVG, PNG @2x, галерея `index.html` |

## Сцены

`scenes/build.py` рисует семь сцен из токенов: приветствие, настройки, обновление, запись,
превью, тёмная тема, редактор. Правки цветов — в `tokens.json`, компонентов — в `build.py`.

```bash
cd scenes
python3 build.py    # svg/*.svg + index.html
./render.sh         # png/*@2x.png через headless Chrome
```

Fraunces подгружается из Google Fonts, поэтому SVG и `index.html` нужно открывать в браузере с
сетью; `render.sh` требует Google Chrome в `/Applications`. В приложение Fraunces кладётся файлом
(SIL OFL, `Design/fonts`): сейчас там только Italic, нужен ещё прямой.
