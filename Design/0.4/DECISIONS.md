# Решения по дизайну 0.4

Дата: 22.10.2026. Формат: решение → почему → как применять.

## 1. Направление: пергамин, чернила, штемпель

**Решение.** Опора — сама бумага glassine (пергамин): полупрозрачные конверты для марок и фото,
филателия, архив. Не «стиль Anthropic».

**Почему.** Тёплая бумага + терракота + сериф в 2026 году читаются как Claude. Мотив из названия
даёт собственное обоснование и уводит от сходства.

**Как применять.** Мотивы — перфорация (превью-марки, марка в окне приветствия), линия отрыва
(панель записи), штемпель (дата на превью, теги в окне обновления), полупрозрачный конверт
(иконка, приветствие), лёгкие «облака» бумаги. Дозированно: в настройках почти без декора.

## 2. Чернила — акцент, красный — только запись

**Решение.** Главные кнопки, тумблеры, выбранное состояние — цвет чернил (`ink`). Красный (`rec`)
только у кнопки записи, индикатора записи и стопа; при необходимости — у разрушительных действий.

**Почему.** В приложении для записи экрана красный значит «идёт запись». Если он везде, кнопка
записи теряет смысл. Чернила совпадают с «paper, ink and Fraunces» и меньше всего похожи на Claude.

**Как применять.** `rec` никогда не акцент и не выбирается в настройках.

## 3. Цвет по смыслу

| Цвет | Значит |
|---|---|
| `ink` | Действие, выбор (по умолчанию) |
| `rec` | Запись |
| `blue_deep` (Stamp) | Glassine что-то нашёл: QR, умные действия; тег Changed |
| `sage_deep` | Готово, успех; тег Added |
| `ochre` | Тег Fixed |

## 4. Контент нейтрален во всех стилях

**Решение.** Затемнение при выделении, холст редактора и сам снимок — без бумаги и фактуры.

**Почему.** Там человек оценивает цвета снимка; кремовое окружение сдвигает восприятие белого.

## 5. Два стиля: Glassine и System

**Решение.** Стиль по умолчанию — **Glassine**. Второй — **System**: нативный macOS, системные
материалы и шрифты; на macOS 26 это Liquid Glass, на 14–15 — обычные материалы. Третьего стиля нет.

**Почему.** «Минимализм» и «Liquid Glass» — один стиль: Liquid Glass есть только на 26+, а
приложение поддерживает 14+, так что запасной вариант и есть минимализм. Каждый стиль умножает
работу (стиль × светлая/тёмная × Increase Contrast). Лицо приложения — то, что стоит по умолчанию.

**Как применять.** Компоненты не спрашивают «какой стиль», а берут токены из `Theme` в
`Environment` (см. BACKLOG). System почти бесплатен — это отказ от переопределений.

## 6. Акцентный цвет на выбор

**Решение.** Settings → General → Appearance: Ink, Sage, Stamp, Ochre, System. По умолчанию — Ink,
если в macOS выбран Multicolor, и System, если пользователь выбрал конкретный цвет.

**Почему.** Конкретный цвет в System Settings — явное желание пользователя; Multicolor —
«пусть приложение решает само». Как определить: глобальный ключ `AppleAccentColor` отсутствует
при Multicolor (недокументировано, но распространено).

**Как применять.** У каждого акцента две пары «заливка + текст поверх» — для светлой и тёмной темы
(`tokens.json → accents`). Для System текст поверх выбирается по яркости. Светлый Sage `#869B80`
с белым текстом даёт 3:1 — для заливки только `#4E6849`.

## 7. Шрифты

**Решение.** Fraunces — заголовки, даты, цифры (таймер, чипы панели записи), SOFT 100, WONK 0, как у
G на иконке. Интерфейс — SF Pro. Метки-капитель и размеры — SF Mono. Три семейства, не больше.

**Почему.** Мягкий Fraunces отличается от острого серифа Anthropic; SF держит нативность.

## 8. Тёмная тема — холодные чернила

**Решение.** Фон — сине-чёрный `#181B21`, а не тёплый графит. Главная кнопка светлая
(`ink` = `#ECEBE4`) с тёмным текстом.

## 9. Доступность

- Текст ≥ 4,5:1. Третичный текст поднят до `#666C77` / `#8A8E97` (был 2,7:1).
- Increase Contrast и Reduce Transparency выключают перфорацию, фактуру бумаги, точки и пунктир.
- Таймер не должен дрожать. У Fraunces нет `tnum` и цифры разной ширины (проверено 22.10.2026),
  поэтому каждая цифра стоит в ячейке фиксированной ширины (на сайте `.timer b`, в SwiftUI — `frame` на цифру).

## 10. Голос и регистр

**Решение.** Title Case для кнопок и пунктов меню, как в Apple HIG («Skip This Version», «Copy QR Link»,
«Check for Updates…»). Подписи, подсказки и описания — обычные предложения. Моноширинные метки — капитель.
(Сначала предлагался sentence case для кнопок; 22.10.2026 оставили Title Case, как рекомендует Apple.)

## 11. Редактор

**Решение.** Холст — нейтральный серый `#E6E6E4`, без бумаги и фактуры (решение 4). В стиле Glassine только
плавающие панели: инструменты сверху, цвет и толщина слева снизу, действия справа снизу, поповер фона.
Выбранный инструмент — заливка `ink`; разделители групп — три точки перфорации; подсказка — карточка
с названием, клавишей и одной-двумя строками. Done — главная кнопка `ink`, Copy / Save / Pin — на `key`.
Буква T инструмента «Текст» — Fraunces, единственный серифный значок.

**Цвета разметки остаются яркими системными** (красный, оранжевый, жёлтый, зелёный, синий, белый,
чёрный): стрелка должна читаться на любом снимке, пастель на нём теряется.

**Пресеты фона снимка — в новой палитре:** Sleeve, Sage, Stamp, Peach, Ink вместо Ocean, Sunset, Mint,
Graphite, Paper. Плюс «продолжить край», прозрачный, белый, чёрный — без изменений.

**Почему.** Редактор — самое большое окно; если раскрасить холст, снимок перестаёт выглядеть как снимок.

  пятисекундный тест («на что похоже?»), бета 0.4 через Sparkle. Если часто отвечают «на Claude» —
  отличий мало.
