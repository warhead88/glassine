# Сайт — план

Тот же язык, что у приложения: токены из `tokens.json`, Fraunces + системный шрифт, перфорация и
штемпели.

**Решено (22.10.2026):** сначала только английский. Фронт — статический, на Python (Jinja + `build.py`,
без Node), хостинг Cloudflare Pages. API — FastAPI + Postgres на VPS за Cloudflare Tunnel. DMG и appcast
остаются на GitHub Releases. Fraunces раздаётся с сайта, не из Google Fonts. Код — в `site/` и `api/`.

## Пожертвования

**Сделано:** BTCPay Server (Bitcoin и Lightning). API создаёт счёт через Greenfield API, вебхук
проверяется по подписи HMAC, а статус всё равно запрашивается у BTCPay. Цель — лист из десяти марок.
Имя и сообщение — только по желанию донора и только после оплаты; email не собирается. Локально —
заглушка оплаты на самом API. BTCPay — на отдельном VPS, Lightning через Tor (туннель Cloudflare
проводит только HTTP), в Lightning держать немного и выводить в холодный кошелёк.

**Дальше, по порядку:**
1. **Monero** — плагин BTCPay: view-only кошелёк, отдельный subaddress на каждый счёт, сумма и
   отправитель скрыты в самой сети. Нужен `monerod` (pruned ≈ 100 ГБ) или чужой узел.
2. **USDT на TON** — один адрес и уникальный комментарий (memo) в счёте; следить за адресом через
   TON API (toncenter / tonapi) или свой узел.
3. **USDT на TRON и ETH/USDT на Ethereum** — у TRC-20 и ERC-20 нет memo: один адрес и уникальная
   сумма (10.000317) либо адрес на каждый счёт из xpub (тогда каждый адрес придётся «подметать», а это
   газ). Свой наблюдатель в API через TronGrid / RPC Ethereum. Баланс одного адреса публичен.
Все варианты — как отдельные «рельсы» за тем же интерфейсом: счёт → наблюдатель → статус.

## Страницы и блоки

1. **Hero.** «A quiet screenshot tool for macOS», кнопка Download, рядом
   «macOS 14+ · Apple Silicon · Free & open source». Версия и размер — из GitHub API.
   Для постоянной ссылки `releases/latest/download/…` нужен DMG без версии в имени
   (сейчас `Glassine-<version>.dmg`).
2. **Живое демо.** Нарисованная сцена, которую посетитель выделяет мышью: лупа, плашка размера,
   превью-марка со штемпелем улетает в угол.
3. **Функции.** Захват (заморозка экрана, лупа), запись — отдельно дорожки звука и ProRes
   (главное отличие), редактор, пины, текст и QR, пипетка и линейка. Ролики — MP4/WebM,
   записанные самим Glassine, не GIF.
4. **Changelog** — собирается из `CHANGELOG.md` при сборке, в стиле тегов Added / Changed / Fixed.
5. **Установка.** На macOS 15+ «right-click → Open» не работает: System Settings →
   Privacy & Security → Open Anyway. Обновить и README. Нотаризация решит это совсем.
6. **FAQ.** Ежемесячный запрос macOS, отключение системных шорткатов, удаление.
7. **Приватность.** Без аналитики (максимум Plausible); скачивания — по статистике релизов GitHub.
8. Русский и английский, OG-картинка в стиле марки, заголовок «Glassine — screenshot tool for Mac».
